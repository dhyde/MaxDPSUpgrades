# MaxDPS.com Upgrades (WoW Forever)

Release distribution repository for **MaxDPS.com Upgrades**, a gear-scoring, dungeon guide, talent plan, and AH upgrade addon for World of Warcraft: Forever.

## Install

- **CurseForge:** https://www.curseforge.com/wow/addons/maxdps-com-upgrades
- **WowUp:** *Get Addons → Install from URL* → `https://github.com/dhyde/MaxDPSUpgrades`
- **Direct download & full guide:** https://maxdps.com/forever/upgrades-addon

Download the latest zip from [Releases](https://github.com/dhyde/MaxDPSUpgrades/releases/latest).
